One-line: the only icon source in NexaFlow — 1.5px stroke line glyphs, never filled, never emoji.

```jsx
<Icon name="dollar" size={16} color="var(--text-muted)" />
```

Sizes in use: 14 (top bar, inside fields), 16 (sidebar, card headers), 18 (metric tiles). Colour via `--text-muted` by default, `--accent` when the row is active.
